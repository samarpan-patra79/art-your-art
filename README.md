# Art Your Art 🎨

A fully functional artist's custom e-commerce single-page app built with **React + Vite + Tailwind CSS**.

## Features

- **Hero Section** – Warm pastel theme with the artist's intro quote and stats
- **Discover Gallery** – 3 animated SVG category cards (Bouquets, Phone Covers, Portraits)
- **Shop with Smart Filters** – Real-time search, price range slider, dynamic category filters
- **Product Detail Page** – Large visuals, materials, delivery info, like/share buttons
- **Reviews & Ratings** – Star rating display + live review submission form
- **Shopping Cart** – Slide-in drawer with quantity controls and live totals
- **Order History** – Color-coded status badges (Delivered, In Transit, Processing)

## Tech Stack

- React 18 + TypeScript
- Vite 7
- Tailwind CSS v4
- shadcn/ui components
- Lucide React icons
- Google Fonts: Playfair Display + Lato

## Getting Started

```bash
pnpm install
pnpm dev
```
